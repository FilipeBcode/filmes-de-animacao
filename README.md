# Catálogo de Filmes de Animação

Projeto acadêmico feito com React, TypeScript, Vite e Material UI. A API do Studio Ghibli fornece a lista e os detalhes dos filmes.

## Executar

```bash
npm install
npm run dev
```

## Páginas

- `/`: lista e busca de filmes por título.
- `/filme/:id`: detalhes do filme.
- `/sobre`: informações sobre o projeto.

## Estrutura

- `src/components`: layout e cartão reutilizável de filme.
- `src/pages`: páginas da aplicação.
- `src/services`: chamadas à API.
- `src/types.ts`: tipo dos dados de filme.
